## Overview
**Pix4Dmapper is a professional photogrammetry application for Windows that converts photos captured by drones, aircraft, or ground-based cameras into precise, georeferenced outputs.** It stitches large sets of overlapping images into orthomosaics, digital surface models, textured 3D meshes, and dense point clouds, giving surveyors, engineers, and GIS professionals reliable measurements without manual fieldwork. The software is built around a guided processing workflow, so users can move from raw imagery to finished deliverables in a structured sequence of steps.

**Which versions of Windows are supported?**
Pix4Dmapper runs on 64-bit Windows 10 and Windows 11, provided your computer meets the recommended hardware specifications for photogrammetry processing.

**Is the Pix4Dmapper interface easy to learn?**
The interface is organized around a step-by-step processing workflow, with project templates and guided settings that help new users move from raw imagery to finished maps and models without deep photogrammetry expertise.

**What kind of imagery can I process with Pix4Dmapper?**
Pix4Dmapper accepts photos captured by drones, fixed-wing aircraft, and ground-based cameras, and supports common image formats used in aerial and close-range photogrammetry.
